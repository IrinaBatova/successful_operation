# Проект "Успешная операция"

## Описание:

Проект "Успешная операция" - это учебный проект на Python для практического освоения навыков по программе обучения "Python-разработчик".

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:IrinaBatova/successful_operation.git
```

2. Все данные о проекте находятся в файле:
```
pyproject.toml
```

## Использование:

1. Запустите файл main.py
2. Введите запрошенные данные.

## Тестирование:

1. Для тестирования используется библиотека pytest
2. Запуск тестирования: введите команду poetry run pytest --cov в терминале.
3. Code coverage 99%.
